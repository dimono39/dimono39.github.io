📊 Генератор аналитического отчёта

📋 Текущие данные для анализа

ℹ️ Как это работает:

Отчёт генерируется на основе данных из вашего appData. При нажатии кнопки:

  1. Берутся актуальные данные из window.appData
  2. Генерируется HTML-отчёт
  3. Открывается в новом окне браузера
  4. Готов к печати на 2-х листах А4
