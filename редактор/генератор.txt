9. Импорт готового комплекта
Обратная операция — пользователь загружает ZIP с комплектом (или три файла отдельно), а система автоматически:

Распознаёт kp*.xlsx → загружает календарь

Распознаёт tm*-sm.xlsx → загружает типовое меню

Файлы YYYY-MM-DD-sm.xlsx → складывает в «сгенерированные»

Удобно для продолжения работы на другом компьютере.

10. Экспорт в PDF-комплект
Один клик → food/*.pdf рядом с *.xlsx. Использовать html2canvas + jsPDF (уже подключены). Особенно полезно для отправки в школу/проверяющим.

21. Автосохранение состояния генератора
Сейчас state живёт только в памяти. Если пользователь случайно обновит страницу — ежедневные меню пропадут. Добавить sessionStorage (не localStorage, чтобы не мешать основному редактору):

javascript
sessionStorage.setItem('generatorState', JSON.stringify({
    calendarData, templateMenuData, dailyMenus, currentYear, ...
}));
И восстанавливать при init().
