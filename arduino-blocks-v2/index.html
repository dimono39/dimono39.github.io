Как начать?

  1. Выберите плату Arduino в верхней панели
  2. Перетащите блок "Программа Arduino" на рабочую область
  3. Добавьте блоки в секции Setup (настройка) и Loop (основной цикл)
  4. Нажмите "Скомпилировать" для генерации кода
  5. Скопируйте код в Arduino IDE или скачайте .ino файл
