Справочник правильных ответов (на основе двух попыток прохождения)

Базовые сведения об ОС и установка
Вопрос 1
Какая версия ОС Astra Linux предназначена для защищённых рабочих мест?
Astra Linux Desktop
Вопрос 2
Какая версия ОС Astra Linux предназначена для планшетов и других мобильных устройств?
Astra Linux Mobile
Вопрос 3
Что означает второе число в номере версии дистрибутива Astra Linux?
Номер сборки
Обычно номер версии формируется как: (1) Главная версия — (2) Номер сборки — (3) Номер обновления/устранения уязвимостей.
Вопрос 4
Какой уровень защищённости необходимо выбрать на шаге установки ОС «Начало»?
В соответствии с приобретённой лицензией
Вопрос 5

Да
Вопрос 6
Требуется ли в Astra Linux установка специальной утилиты для подготовки установочного USB-носителя?
Нет
Вопрос 7
Возможна ли установка ОС Astra Linux с установочного USB-носителя, если в BIOS не настроен запуск компьютера с внешнего носителя?
Нет

Вопрос 8

В нижней
Вопрос 9

Недавно запущенные программы
Вопрос 10
Какие настройки значков на панели задач доступны? (Множественный выбор)
  • Скрытие значков выбранных программ на панели
  • Закрепление значка программы на панели переключения задач
  • Группировка нескольких значков одной программы
  • Изменение размера
  • Отображение значков без надписей
Вопрос 11
Как можно увеличить пространство панели переключения задач?
Добавить ряд кнопок
Вопрос 12
Как добавить каталог в список избранных на боковой панели Менеджера файлов?
Вызвать контекстное меню на каталоге, в нём выбрать пункт «Отправить», и в раскрывшемся подменю выбрать «Избранное»
Вопрос 13
Какими способами можно запустить Менеджер файлов? (Множественный выбор)
  • В группе Компьютер меню Пуск выбрать желаемый каталог
  • С помощью ярлыка Мой компьютер на Рабочем столе
  • В контекстном меню панели задач выбрать пункт Менеджер файлов…
  • На панели задач нажать значок папки
Вопрос 14
Какой путь до файла является абсолютным?
/home/user/Документы/Приказ.odt
Абсолютный путь всегда начинается с корневого каталога «/» и содержит полный путь от корня.
Вопрос 15
Какое условное обозначение получает основной диск в Astra Linux?
sda
Вопрос 16
Как можно перейти к настройкам экранов? (Множественный выбор)
  • С помощью комбинации клавиш Ctrl+Alt+D
  • Через контекстное меню рабочего стола
  • Через параметры системы
  • Через контекстное меню панели задач
Вопрос 17
Какое сочетание клавиш можно использовать, чтобы свернуть окно программы?
Meta+Вниз
Вопрос 18
Какие параметры можно задать для мыши? (Множественный выбор)
  • Уровень заряда батареи мыши, при котором будет отображаться предупреждение
  • Действие по нажатию на колесо
  • Скорость указателя
  • Направление прокрутки
Администрирование, терминал и сеть
Вопрос 19

С помощью контекстного меню в списке отметить нужную программу для установки и применить список изменений

В Synaptic раскрыть пункт «Настройки» главного меню и выбрать пункт «Репозитории»

Возможно ли добавление сторонних репозиториев?
Да
Вопрос 23

Вопрос 25

Автоматически дописать вводимую команду
Вопрос 26
Как выйти из руководства по программе в терминале?
Нажать клавишу q
Вопрос 27
Какую команду следует выполнить в терминале для запуска Midnight Commander?
mc
Вопрос 28

$USER
Вопрос 29
Какую деятельность по администрированию ОС можно автоматизировать с помощью bash? (Множественный выбор)
  • Работа с файлами и каталогами
  • Управление пользователями
  • Запуск программ
  • Установка и удаление программ
Вопрос 30
Обладает ли правами суперпользователя учётная запись, созданная при установке системы?
Да
Первый созданный пользователь обычно добавляется в группу sudo и может выполнять команды от имени администратора.
Вопрос 31
Можно ли ограничить срок действия учётной записи?
Да
Вопрос 32
В какой момент задаётся пароль для созданного через командную строку пользователя?
После выполнения команды useradd, с помощью команды passwd
Вопрос 33
Всегда ли удаляется домашний каталог при удалении пользователя?
Только при подтверждении
При удалении пользователя через графический интерфейс или команду обычно предлагается опция удаления домашней папки, которая требует явного подтверждения.
Вопрос 34
Кто может изменить дату и время на компьютере?
Только администратор
Вопрос 35
Для чего предназначен режим «Киоск»?
В этом режиме пользователь может запускать только указанные в его профиле приложения
Вопрос 36
В какой момент указывается драйвер для принтера?
После выбора принтера в мастере установки

  • Установить баланс между каналами
  • Регулировать уровень громкости для приложения
  • Переключиться между звуковыми устройствами
Вопрос 38
