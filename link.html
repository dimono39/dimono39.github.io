Важно: Этот код, скорее всего, завершится ошибкой из-за политики CORS (Cross-Origin Resource Sharing), если он запущен не на самом домене мониторингпитание.рф. Браузер блокирует такие запросы из соображений безопасности.

Проверьте консоль браузера (F12) для просмотра ошибок.

Как можно попробовать найти реальный API?

  1. Откройте Инструменты разработчика (F12) → вкладка Network (Сеть).
  2. Перезагрузите страницу https://мониторингпитание.рф/#/profile?id=28605.
  3. Ищите запросы типа fetch или xhr, которые загружают данные для таблиц. В ответе (вкладка Response) могут быть JSON-данные.
  4. Если такие запросы найдены, их URL можно попытаться использовать в коде выше.
